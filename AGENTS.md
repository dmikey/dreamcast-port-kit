# Dreamcast port kit

For Dreamcast disc extraction, decompilation/recompilation, or port bring-up,
read `skills/dreamcast-port/SKILL.md`. Keep reusable fixes in the pinned shared
toolchain patches; keep addresses and bootstrap details in exact-hash title
profiles. Do not put disc-derived data in tracked source.

Run the disc/parser tests and compiler execution tests for the affected stages.
A synthetic fixture passing is not evidence that a commercial game is playable.
